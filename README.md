# CS-465
This project is a full stack web application that serves both the customer-facing and administrative sides of the Travlr Getaways website. The customer side allows users to view available travel packages, while the admin side enables authorized users to securely manage trip information. Throughout the development process, I combined Express HTML templates, JavaScript, and a single-page application (SPA) structure for the frontend. Express HTML and JavaScript provided a simple, server-rendered approach that made integration with backend routes efficient and reliable, while the SPA allowed for a smoother, more dynamic user experience by updating content without requiring full page reloads. The backend used a NoSQL MongoDB database because of its flexibility, scalability, and ability to store unstructured data in a way that integrates naturally with JSON and JavaScript-based applications. MongoDB’s schema-less design made it ideal for handling travel data and user information without needing a rigid table structure.

JSON, or JavaScript Object Notation, played a key role in linking the frontend and backend systems. While JavaScript executes the logic of the application, JSON serves as a lightweight format for transferring structured data between the client and the server. Using JSON made it possible for the frontend to send and receive data efficiently through API endpoints, ensuring that changes made in the database were quickly reflected on the user interface. During the project, I refactored code to improve performance and organization, particularly by modularizing route logic, reusing UI components, and simplifying functions for better maintainability. The use of reusable user interface elements reduced redundancy, improved consistency, and made it easier to scale or modify the project later.

Testing the full stack application involved verifying API endpoints and ensuring that CRUD operations (Create, Read, Update, Delete) worked as intended. I used methods such as GET, POST, PUT, and DELETE to test data requests and responses through tools like Postman. Once authentication and security features were added, testing became more complex since it required handling authorization tokens and secure sessions. Implementing these security layers deepened my understanding of how methods, endpoints, and authentication systems work together to maintain both functionality and data integrity in a secure application.

Overall, this course has been instrumental in helping me progress toward my professional goals by giving me hands-on experience with real-world full stack development. I strengthened my skills in JavaScript, Node.js, Express, MongoDB, and API integration while also learning the importance of testing, refactoring, and secure design. I now have a stronger understanding of how frontend and backend systems communicate and how to create efficient, maintainable, and secure web applications. These experiences have made me a more confident and marketable candidate for future roles in software and data development.
